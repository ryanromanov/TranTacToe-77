**New in Tic-Tac-Tran, FORTRAN 77 edition 1.1.0**

- **The computer can move first.** A new prompt after the difficulty asks who starts.
- **Minimax sets traps.** When several moves are equally safe, `tictac77-minimax` picks the one that leaves you the most ways to lose. Against a random player its win rate rises from 80.6% to 88.0%, and it still never loses.
- **`YES` works.** The retire prompt now accepts `yes` in any case.
- **Fits 80 columns.** Every line the game prints fits a standard 80-column terminal.
- **Checked before shipping.** The release build now plays complete games with each binary before publishing.

The game now asks for input in this order: lucky number, difficulty (1–3), who moves first (1 for you, 2 for the computer), then your moves as `row col`. Enter `0 0` to retire.
