The first release of **Tic-Tac-Tran, FORTRAN 77 edition**: the terminal tic-tac-toe game from [TranTacToe](https://github.com/ryanromanov/TranTacToe), ported to standard ANSI FORTRAN 77 with no vendor extensions.

Each download contains two builds that differ only in how difficulty 3 plays. Both are unbeatable.
- `tictac77-rules` plays by classic rules: win, block, fork, block fork, centre, corner, side.
- `tictac77-minimax` searches the full game tree on a stack of its own, since F77 has no recursion.

**To play:** unpack the download for your platform and run `./tictac77-rules` or `./tictac77-minimax`. The game asks for:
1. a lucky number, which seeds the random number generator because F77 has no clock,
2. a difficulty from 1 to 3,
3. your moves, as `row col`.

Enter `0 0` to retire.
